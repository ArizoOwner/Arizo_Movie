**Arizo_Movie** یک ربات تلگرامی هوشمند، فوق‌سریع و **۲۴ ساعته سرورلس (Serverless)** است که مخصوص مدیران کانال‌های فیلم و سریال طراحی شده است. این ربات مشخصات آثار سینمایی را مستقیماً از پایگاه بین‌المللی TMDB استخراج کرده، ژانرها را با هشتگ‌های دقیق فارسی می‌سازد، گالری پوسترهای باکیفیت را در قالب دکمه‌های شیشه‌ای رنگی نمایش می‌دهد و با فوروارد یا ارسال لینک فایل، پست نهایی را بلافاصله در کانال مقصد منتشر می‌کند.

این پروژه به‌طور کامل برای اجرا بر بستر **Cloudflare Workers** به همراه پایگاه داده ابری **Cloudflare D1** بهینه‌سازی شده و **بدون نیاز به سرور مجازی (VPS) یا هزینه ماهیانه**، به‌صورت شبانه‌روزی و بدون حتی ۱ ثانیه قطعی کار می‌کند.

## ✨ امکانات و قابلیت‌های کلیدی

- ⚡ **معماری سرورلس ۲۴/۷ (Edge-Native):** اجرا روی شبکه جهانی لبه کلادفلر با زمان پاسخ زیر ۵۰ میلی‌ثانیه، بدون نیاز به نگهداری سرور یا ترس از خاموش شدن.
- 🧙‍♂️ **ویزارد راه‌اندازی تحت وب (`/setup`):** رابط گرافیکی مدرن (Glassmorphism Dark) برای ثبت و بررسی آنی توکن‌ها، ساخت جداول دیتابیس و ثبت وب‌هوک با یک کلیک.
- 🔒 **امنیت کامل توکن‌ها:** هیچ کلید یا توکنی در سورس‌کد هاردکد نشده و همه‌چیز به‌صورت پویا از طریق ویزارد وب یا سکرت‌های امن مدیریت می‌شود.
- 🎬 **جستجوی هوشمند TMDB:** پشتیبانی از نام‌های فارسی و انگلیسی فیلم‌ها و سریال‌ها، تفکیک خودکار نوع مدیا و استخراج دقیق امتیاز و سال انتشار.
- 🎭 **هشتگ‌گذاری استاندارد فارسی:** تبدیل خودکار ژانرهای انگلیسی به هشتگ‌های رسمی فارسی (`#اکشن`, `#علمی_تخیلی`, `#درام`, ...).
- 📺 **مدیریت فصول سریال‌ها:** ساخت فرمت سال انتشار و شماره سیزن‌ها بر اساس دیتای رسمی TMDB.
- 🖼 **گالری تعاملی پوسترها:** ورق زدن پوسترهای اورجینال با دکمه‌های اینلاین استایل‌دار (`◀️ قبلی`، `بعدی ▶️`، `💎 تایید پوستر`) با کنترل دقیق حجم برای جلوگیری از خطای تلگرام.
- 🔗 **اتصال خودکار با فوروارد:** فوروارد کردن فایل فیلم یا ارسال لینک پیام کانال خصوصی/عمومی برای انتشار خودکار پست متصل به فایل در کانال مقصد.
- 💾 **پایگاه داده ماندگار D1:** ذخیره دائم سشن‌های هر کاربر و کانال‌های مقصد بدون اتکا به حافظه فرار (In-Memory).
- 🔄 **خودترمیمی و پایش ۲۴ ساعته (Cron Check):** بررسی خودکار وضعیت وب‌هوک هر ۳۰ دقیقه توسط کرون‌جاب کلادفلر.
- 🚀 **استقرار خودکار (CI/CD):** استقرار آنی بر روی کلادفلر با هر `git push` به ریپازیتوری توسط GitHub Actions.

## 🚀 راهنمای سریع راه‌اندازی

### مرحله ۱: فورک یا کلون پروژه
ابتدا مخزن را کلون کنید:
```bash
git clone https://github.com/ArizoOwner/Arizo_Movie.git
cd Arizo_Movie
```

### مرحله ۲: تنظیم GitHub Secrets (جهت استقرار خودکار)
در مخزن گیت‌هاب خود به مسیر زیر بروید:
**Settings ➜ Secrets and variables ➜ Actions**

دو متغیر زیر را ایجاد کنید:
1. `CLOUDFLARE_API_TOKEN`: توکن دسترسی کلادفلر (با مجوز Workers و D1).
2. `CLOUDFLARE_ACCOUNT_ID`: شناسه اکانت کلادفلر شما.

از این پس هر تغییری که در شاخه `main` اعمال کنید، به صورت اتوماتیک مستقر می‌شود!

### مرحله ۳: ساخت دیتابیس D1 (اختیاری از طریق CLI)
```bash
npx wrangler d1 create arizo-movie-db
# شناسه database_id نمایش داده شده را در wrangler.toml قرار دهید
npx wrangler d1 execute arizo-movie-db --file=./schema.sql
npx wrangler deploy
```

## 🧙‍♂️ ویزارد تحت وب (`/setup`)

پس از استقرار ورکر، آدرس ورکر خود را به همراه مسیر `/setup` در مرورگر باز کنید:
```
https://arizo-movie.<your-subdomain>.workers.dev/setup
```

در صفحه باز شده:
1. **توکن ربات تلگرام (BOT_TOKEN):** توکن دریافتی از [@BotFather](https://t.me/BotFather) را وارد کرده و روی **"🔍 بررسی توکن"** کلیک کنید.
2. **کلید TMDB:** کلید دریافتی از [TheMovieDB](https://www.themoviedb.org/settings/api) را وارد کرده و روی **"🔍 بررسی کلید"** کلیک کنید.
3. **شناسه ادمین:** شناسه عددی تلگرام خود را وارد کنید.
4. روی دکمه **"🚀 راه‌اندازی، اتصال D1 و ثبت نهایی وب‌هوک"** کلیک کنید.

تمام کارها (ساخت دیتابیس، ثبت وب‌هوک، تنظیم دستورات رسمی در بات‌فادر) در چند ثانیه انجام می‌شود و ربات شما بلافاصله ۲۴ ساعته فعال خواهد بود!

## 🤖 دستورات ربات تلگرام

| دستور | توضیح |
|---|---|
| `/start` | شروع ربات، نمایش منوی اصلی، وضعیت اتصال به کانال و آغاز جستجو |
| `/setchannel` | ثبت یا تغییر کانال مقصد (پشتیبانی از آیدی عمومی `@channel` و لینک کانال خصوصی) |
| `/help` | راهنمای کامل استفاده، فوروارد و ساخت پست |
| `/cancel` | انصراف از عملیات جاری و پاکسازی سشن |

## 🐳 اجرای نسخه پایتون (اختیاری با Docker یا محلی)

اگر تمایل به اجرای نسخه پایتونی به شیوه Polling دارید:

```bash
# تنظیم متغیرهای محیطی
export BOT_TOKEN="توکن_ربات_تلگرام"
export TMDB_KEY="کلید_ای‌پی‌آی_تی‌ام‌دی‌بی"

# نصب وابستگی‌ها و اجرا
pip install -r requirements.txt
python app3.py
```

یا با داکر:
```bash
docker build -t arizo-movie .
docker run -d --name arizo-movie -e BOT_TOKEN="xxx" -e TMDB_KEY="yyy" arizo-movie
```
